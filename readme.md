# Chinchilla

โปรเจกต์เพื่อการเรียนรู้ที่พัฒนาขึ้นระหว่างการเรียนที่ **Bangkok University (มหาวิทยาลัยกรุงเทพ)** และ **42 Bangkok KMITL** เพื่อฝึกเขียน Python จัดโครงสร้างโปรแกรมเป็นโมดูล และทดลองปรับแต่งโมเดลภาษาให้ตอบคำถามภาษาไทยและภาษาอังกฤษ รวมถึงสร้างคำสั่งเทอร์มินัลจากภาษาธรรมชาติ

โปรเจกต์ยังอยู่ระหว่างการพัฒนาและทดลอง ผลลัพธ์จากโมเดลอาจไม่ถูกต้องเสมอไป

## ความสามารถ

- เตรียมชุดข้อมูลถามตอบภาษาไทยและภาษาอังกฤษ พร้อมตัวอย่างคำขอและคำสั่งเทอร์มินัล
- ฝึก LoRA บนโมเดลฐานแบบ 4-bit ด้วย MLX และเลือก checkpoint สำหรับรวมโมเดล
- สนทนากับโมเดลผ่านเทอร์มินัล โดยเลือกหน้าตาแบบข้อความธรรมดาหรือ Rich ได้
- แปลงคำขอเป็นคำสั่งสำหรับ macOS พร้อมตรวจความเสี่ยงเบื้องต้นและขอยืนยันก่อนรันตามเงื่อนไขของโปรแกรม
- บันทึกคำสั่งลง CSV ค้นหา ให้คะแนน ลบรายการ ดูสถิติ และส่งออกรายงานข้อความ
- แปลงโมเดลเป็น GGUF ด้วย llama.cpp และสร้าง Dockerfile สำหรับให้บริการโมเดล

## โครงสร้างโปรเจกต์

```text
chinchilla/
├── command_log.py       จุดเริ่มต้นของสมุดบันทึกคำสั่ง
├── command_log/         จัดการ CSV ตรวจข้อมูล คำนวณสถิติ และแสดงเมนู
├── pipline.py           จุดเริ่มต้นของคำสั่งฝึกโมเดลและแชท
├── pipeline/            เตรียมข้อมูล ฝึกโมเดล สร้างคำตอบ และจัดการแชท
├── test_command.log.py  ชุดทดสอบสมุดบันทึกคำสั่ง
├── data/                ข้อมูลฝึก ข้อมูลประเมิน และบันทึกคำสั่ง
├── outputs/             โมเดล adapter และผลลัพธ์จากการฝึก
└── reports/             รายงานสรุปที่ส่งออก
```

โฟลเดอร์ `data/`, `outputs/` และ `reports/` เป็นไฟล์ที่สร้างระหว่างใช้งานและไม่ได้เก็บไว้ใน Git ต้องเตรียมข้อมูลและโมเดลก่อนใช้ส่วนแชท

ชื่อไฟล์สำหรับรัน pipeline ในโปรเจกต์นี้คือ **`pipline.py`**

## เริ่มใช้งานสมุดบันทึกคำสั่ง

ส่วนนี้ใช้ไลบรารีมาตรฐานของ Python และใช้งานได้โดยไม่ต้องติดตั้งหรือโหลดโมเดล

รันจากโฟลเดอร์หลักของโปรเจกต์:

```bash
python3 command_log.py
```

เลือกไฟล์บันทึกเองได้:

```bash
python3 command_log.py --file data/my_commands.csv
```

เมนูรองรับการเพิ่ม ดู ค้นหา ให้คะแนน และลบรายการ รวมถึงดูสถิติและส่งออกรายงานไปที่ `reports/summary.txt`

## ติดตั้งส่วนโมเดล

เส้นทางการฝึกด้วย MLX ออกแบบสำหรับ macOS บน Apple Silicon ต้องมีอินเทอร์เน็ตสำหรับดาวน์โหลดโมเดลและชุดข้อมูล รวมถึงพื้นที่ว่างสำหรับเก็บไฟล์ที่ดาวน์โหลดและผลลัพธ์การฝึก

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U mlx-lm datasets transformers huggingface_hub rich
```

โมเดลเริ่มต้นคือ `mlx-community/Qwen2.5-1.5B-Instruct-4bit` สำหรับฝึก และ `Qwen/Qwen2.5-1.5B-Instruct` สำหรับรวม adapter

## เตรียมข้อมูลและฝึกโมเดล

รันตามลำดับจากโฟลเดอร์หลักของโปรเจกต์:

```bash
python pipline.py prepare
python pipline.py train
python pipline.py merge --checkpoint best
python pipline.py test --question "เมืองหลวงของประเทศไทยคืออะไร"
```

ข้อมูลจะถูกเขียนไปที่ `data/train.jsonl` และ `data/valid.jsonl` ส่วน adapter อยู่ที่ `outputs/lora-adapter/` และโมเดลที่รวมแล้วอยู่ที่ `outputs/merged/`

## สนทนาและสร้างคำสั่งเทอร์มินัล

เมื่อมีโมเดลใน `outputs/merged/` แล้ว เปิดหน้าต่างแชทได้ด้วย:

```bash
python pipline.py chat
```

ในแชทใช้ `/help` เพื่อดูคำสั่งทั้งหมด, `/reset` เพื่อล้างประวัติ และ `/exit` เพื่อออก ใช้ `!` นำหน้าข้อความเมื่อต้องการสร้างคำสั่งเทอร์มินัล เช่น `!ดูพื้นที่ดิสก์ที่เหลือ`

หากต้องการดูคำสั่งที่โมเดลสร้างโดยไม่รัน:

```bash
python pipline.py shell "แสดงรายชื่อไฟล์ทั้งหมด" --dry-run
```

ควรอ่านคำสั่งก่อนยืนยันให้รัน เพราะการตรวจความเสี่ยงเป็นเพียงการตรวจตามรูปแบบที่กำหนดไว้ และไม่ครอบคลุมคำสั่งอันตรายทุกกรณี

## ทดสอบโปรแกรม

```bash
python3 test_command.log.py -v
```

ชุดทดสอบนี้ตรวจการจัดการไฟล์ CSV การตรวจข้อมูล การจำแนกภาษาและความเสี่ยง และการคำนวณสถิติของสมุดบันทึกคำสั่ง โดยใช้ไฟล์ชั่วคราว ไม่ได้ประเมินความแม่นยำของโมเดลภาษา

ดูตัวเลือกเพิ่มเติมของแต่ละคำสั่งได้ด้วย:

```bash
python3 pipline.py --help
python3 pipline.py train --help
python3 pipline.py quantize --help
```
